# SIGNAL DESK

기술적 지표(이동평균/RSI/MACD/볼린저밴드) + 뉴스 헤드라인 감성분석을 결합해서,
미국·한국 우량주 유니버스를 자동 스캔하고 매수/매도 후보를 보여주는
**휴대폰 설치형 앱(PWA)**입니다.

**이 앱은 자동으로 매매하지 않습니다.** "매수 후보"는 설정한 규칙상 점수가
높은 종목일 뿐 투자 권유가 아니고, 실제 주문은 토스증권/한국투자증권 앱에서
본인이 직접 실행해야 합니다.

## 주요 기능

- **자동 스캔**: 관심종목을 직접 입력할 필요 없이, 미리 정한 종목 유니버스
  (미국 15개 + 한국 15개)를 매번 전부 스캔해서 점수 높은 순으로 정렬
- **종목 직접 검색**: 유니버스에 없는 종목도 티커를 입력해서 바로 조회 가능
  (예: `AAPL`, `005930.KS`)
- **매수/매도 후보**: 종합점수 +40 이상은 매수 후보, -20 이하는 매도/주의 후보로 자동 분류
- **상승 확률(참고용)**: "과거에 지금과 비슷한 신호가 떴을 때 5거래일 후 실제로
  올랐던 비율"을 실제 계산해서 표본 수와 함께 표시. 통계적으로 검증된 미래
  예측이 아니라 과거 데이터 기반 참고 지표임을 명시함
- **시장 현황**: S&P500/나스닥/코스피/코스닥 지수 + 전체 유니버스의 매수/매도
  비율(breadth)
- **1분마다 자동 갱신**: 앱이 화면에 보이는 동안만 (백그라운드에서는 배터리/API
  절약을 위해 자동 정지)
- **푸시 알림**: 강한 매수 신호(종합점수 60 이상)가 새로 뜨면 알림
- **백테스트**: 과거 데이터로 기술적 신호 전략의 실제 성과 검증

## 폰에 설치하기 (배포 후)

1. 아래 "배포하기"로 인터넷 주소를 만든다 (한 번만 하면 됨)
2. 폰 브라우저로 그 주소 접속
3. Android(Chrome): 상단 "홈 화면에 추가" 버튼 탭
   iPhone(Safari): 공유 버튼(□↑) → "홈 화면에 추가"
4. 홈 화면에 아이콘이 생기고, 이후엔 일반 앱처럼 탭해서 실행

## 배포하기 (무료, 최초 1회 설정)

### 1단계: Vercel 배포

1. https://vercel.com 가입 (GitHub 계정으로 가능)
2. 이 프로젝트 폴더를 GitHub 저장소로 올리기
3. Vercel에서 "New Project" → 그 저장소 선택 → Deploy
4. `api/` 폴더는 자동으로 서버리스 함수로, 나머지는 정적 파일로 배포됨

여기까지만 해도 스캔/시장현황/백테스트는 바로 동작합니다.
푸시 알림까지 쓰려면 아래 2~3단계도 필요합니다.

### 2단계: 푸시 알림 활성화 (선택)

```bash
npm install
npm run generate-vapid-keys
```

출력된 `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`를 Vercel
프로젝트 설정 → Environment Variables에 등록.

그리고 Vercel 프로젝트에서 **Storage → KV(또는 Upstash Redis) 추가**
(무료 티어 있음) → 프로젝트에 연결하면 `KV_REST_API_URL` 등 필요한
환경변수가 자동으로 채워집니다. (푸시 구독자 목록을 저장하는 용도)

배포를 다시 트리거하면(재배포) 적용됩니다.

### 3단계: 자주 체크하기 (선택)

Vercel 무료 플랜은 정기 실행(크론)이 **하루 1번**으로 제한되어 있어서,
더 자주 신호를 체크하려면 **GitHub Actions**(무료)를 씁니다.

1. 이 저장소의 GitHub Settings → Secrets and variables → Actions에서:
   - `APP_URL`: 배포된 앱 주소 (예: `https://signal-desk.vercel.app`)
   - `CRON_SECRET`: 아무 문자열이나 정해서 등록 (예: 랜덤 문자열),
     Vercel 프로젝트의 `CRON_SECRET` 환경변수에도 **동일한 값**을 등록
2. `.github/workflows/check-signals.yml`이 15분마다 자동으로
   `/api/cron/check-signals`를 호출해서 강한 매수 신호를 체크하고 푸시를 보냄
3. GitHub Actions 탭에서 "Run workflow"로 수동 실행도 가능

**한계**: GitHub Actions 무료 스케줄도 정확한 시각을 보장하진 않고
몇 분 지연될 수 있습니다. 실시간 급등 알림 수준의 즉시성은 기대하기 어렵습니다.

## 로컬에서 미리 확인하기 (선택)

```bash
npm install
npm start
```
http://localhost:3000 에서 배포 전 테스트 가능. `/api/push`, `/api/cron`은

## 데이터 소스 (모두 무료, API 키 불필요 — 뉴스 감성분석 고도화만 선택적으로 키 필요)

- 시세/차트: Yahoo Finance 공개 차트 엔드포인트
- 뉴스: Yahoo Finance RSS 피드
- 감성분석: 내장 키워드 기반 스코어링 (기본) / Claude API (선택)

## 종목 유니버스 수정

`lib/universe.js`의 `US_UNIVERSE` / `KR_UNIVERSE` 배열을 직접 수정하면 됩니다.
유니버스가 커질수록 스캔 시간과 API 호출량이 늘어나니, 무료 플랜에서는
40~50개 이내를 권장합니다 (Vercel 서버리스 함수 실행시간 제한 때문).

## 신호 계산 방식

- 기술점수 65% + 뉴스감성 35% = 종합점수 (-100 ~ +100)
- +40 이상: 매수 우세 / -40 이하: 매도 우세 / 그 사이: 중립
- 매수 후보 화면: 종합점수 +40 이상 상위 10개
- 매도 후보 화면: 종합점수 -20 이하 하위 10개
- `lib/signalEngine.js`에서 가중치·임계값 조정 가능

## 상승 확률 계산 방식 (중요 — 반드시 읽어주세요)

`lib/backtest.js`의 `computeUpProbability()`가 계산합니다. 방식:
1. 3년치 과거 데이터를 하루하루 되짚으며, 그날 시점까지의 데이터로 기술점수를 계산
2. 지금 신호의 점수와 ±15점 이내로 비슷했던 과거 날짜들을 모두 찾음
   (표본이 8개 미만이면 자동으로 허용 범위를 넓혀 재시도 — 화면에 "완화적용"으로 표시)
3. 3거래일 / 5거래일 / 10거래일 후 각각 상승 비율과 평균 수익률(%)을 계산

이건 머신러닝 예측이 아니라 **단순 과거 빈도 통계**입니다. 표본이 적으면
("표본 적음" 표시) 의미가 거의 없고, 표본이 많아도 과거 패턴이 미래에
반복된다는 보장은 없습니다. 하나의 참고 지표로만 쓰세요.

## 뉴스 감성분석 (키워드 방식 개선 내역)

- **부정어 처리**: "not growing", "no decline" 같은 표현을 인식해서 반전 처리
- **최신 가중치**: 오늘 뉴스는 가중치 1.0, 10일 전 뉴스는 0.3까지 낮아짐
- **다중 소스**: Yahoo Finance RSS + 구글 뉴스 RSS 두 곳에서 수집 후 중복 제거,
  10일 이내 뉴스만 사용, 최신순 정렬

## 한국투자증권 계좌 연동 (신규)

잔고·보유종목 조회, 매수/매도 주문(수동 확인 방식)이 가능합니다.

**중요 — MCP 아님**: 한국투자증권이 자체 MCP(KIS Trading MCP)를 공개하긴 했지만,
그건 "Claude가 대화 중 KIS를 호출하는 기능"이라 이 웹앱과는 관계없습니다.
이 앱은 KIS Open API(REST)를 서버 코드에서 직접 호출하는 방식입니다.

**안전장치**:
- 기본값은 **모의투자**. 실전투자로 쓰려면 `KIS_ENV=real`을 명시적으로 설정해야 함
- 매수/매도는 **버튼 → 확인 모달 → 사용자가 직접 "확인" 눌러야 실행**되는 구조.
  자동으로 나가는 주문은 없음 (서버 API 자체가 `confirm:true` 없이는 거부함)
- 현재 국내주식(KRX)만 지원. `.KS`/`.KQ` 종목에만 매수/매도 버튼이 뜸

**설정 방법**: Vercel 환경변수에 아래 값 등록 (모의투자 기준, 실전은 `_REAL` 접미사로 별도 등록)

```
KIS_ENV=mock
KIS_APP_KEY_MOCK=발급받은 모의투자 앱키
KIS_APP_SECRET_MOCK=발급받은 모의투자 앱시크릿
KIS_CANO_MOCK=계좌번호 앞 8자리
KIS_ACNT_PRDT_CD_MOCK=01
```

계좌 조회 토큰은 Vercel KV에 캐싱되므로(23시간), 푸시 알림 설정 때 만든 KV가
이미 있다면 그대로 재사용됩니다.

### 해외주식 (미국) 지원

국내주식과 같은 계좌/키를 그대로 씁니다. 접미사 없는 순수 알파벳 티커
(예: `AAPL`, `TSLA`)를 검색하면 매수/매도 버튼이 뜹니다.

**⚠ 중요 — 실전 전환 전 필독**: 해외주식 주문 TR_ID(`JTTT1002U`,
`JTTT1006U`, `VTTT1002U`, `VTTT1001U`)는 여러 커뮤니티 자료를 교차 확인해서
넣었지만, KIS 공식 API 문서로 100% 대조하지는 못했습니다. **모의투자로
충분히 테스트해보고, 실전(`KIS_ENV=real`) 전환 전에 반드시**
https://apiportal.koreainvestment.com 에서 `/uapi/overseas-stock/v1/trading/order`
문서의 정확한 TR_ID를 재확인하세요. 틀린 TR_ID로 실전 주문을 시도하면
최악의 경우 의도와 다른 주문이 나갈 수 있습니다.

또한 해외주식은 안전을 위해 **지정가만 지원**합니다 (시장가 TR_ID는
검증이 덜 되어 제외). 거래소는 기본값 `NASD`(나스닥)로 고정돼 있어서,
뉴욕거래소(NYSE) 상장 종목은 `lib/kisClient.js`의 `exchange` 파라미터를
수정해야 할 수 있습니다.

### 한국투자증권 MCP에 대해 (참고)

한국투자증권이 자체 MCP("KIS Trading MCP")를 공개하긴 했지만, 이건
**Claude 같은 AI가 대화 중에 KIS API를 직접 호출하는 기능**이라 이
웹앱과는 별개입니다. claude.ai 앱/모바일 인터페이스에서는 이런 개별
서드파티 MCP 서버를 직접 추가할 수 없고(Claude Desktop이나 Claude Code,
또는 Enterprise 관리자 설정에서만 가능), 이 신호 앱은 그것과 무관하게
서버 코드에서 KIS REST API를 직접 호출하는 지금 방식으로 계속 동작합니다.

## Claude API 감성분석 (선택, 더 정확함)

Vercel 환경변수에 `ANTHROPIC_API_KEY`를 추가하면 키워드 매칭 대신 Claude가:
- 각 헤드라인이 **실제로 이 종목과 관련 있는지**부터 판단해서 무관한 뉴스를 걸러냄
  (검색 기반 수집이라 관련 없는 뉴스가 섞이는 문제를 완화)
- 관련 있는 뉴스만 반어법/맥락까지 고려해서 -2~+2로 평가, 최신 뉴스에 더 비중
- 화면에 헤드라인별로 "관련성"과 "긍정/부정" 태그가 함께 표시됨 (무관한 뉴스는 흐리게 표시)

키가 없거나 실패 시 자동으로 키워드 방식으로 폴백합니다.

## 백테스트

백테스트 패널에서 티커 입력 후 실행하면, 과거 데이터에 기술적 신호
규칙을 그대로 적용했을 때의 가상 수익률을 계산합니다.

**한계**: 과거 뉴스 헤드라인은 구할 수 없어서 기술적 지표(65% 비중)만
검증합니다. 실제 신호(기술+뉴스 35%)와는 다른 결과일 수 있고, 과거
성과가 미래 성과를 보장하지 않습니다.

## 파일 구조

```
index.html, style.css, app.js   → 프론트엔드 (정적 파일)
manifest.json, sw.js, icons/    → PWA 설치/오프라인/푸시 지원
api/                             → Vercel 서버리스 함수
  scan.js                        → 유니버스 전체 스캔
  market-overview.js             → 지수 현황
  signal/[ticker].js             → 단일 종목 신호
  backtest/[ticker].js           → 백테스트
  push/                          → 푸시 구독 관리
  cron/check-signals.js          → 신호 변화 감지 + 푸시 발송 (외부 스케줄러가 호출)
server.js                        → 로컬 개발용 Express 서버 (배포에는 안 씀)
lib/                             → 신호 계산 로직 (api와 server.js가 공유)
scripts/generate-vapid-keys.js   → 푸시 알림용 키 생성 스크립트
.github/workflows/               → GitHub Actions 스케줄러 (무료 크론 우회)
```

## 알려진 한계 / 앞으로 더 고칠 것

- Yahoo Finance는 비공식 무료 엔드포인트라 트래픽이 몰리면 일시 차단될 수 있음
- 유니버스가 고정되어 있어 원하는 특정 종목이 목록에 없으면 직접 `lib/universe.js`
  수정 필요 (다시 개별 검색 기능을 원하면 `/api/signal/[ticker]`가 그대로 살아있음)
- 실기기(iOS/Android) 설치 및 푸시 수신 테스트는 아직 안 해봄 — 배포 후 직접 확인 필요
- 한국 개별 종목 뉴스가 영어 위주라 감성분석 정확도가 낮을 수 있음
